# Horiadev Shop

- A minimalist online store built with React.js, Styled Components and Context API.
- Uses a fake JSON for products

## Tech Stack

- React.js (19.1.0)
- Material UI
- Context API
- Styled Components (6.1.18)
- Fake JSON (mock data)

## Dependecies

- Styled Components (6.1.18)
- "@fortawesome/free-solid-svg-icons": "^6.7.2"
- "@fortawesome/react-fontawesome": "^0.2.2"
- "react-router-dom": "^6.30.1"
- "locomotive-scroll": "^4.1.4",

## How to run the project

1. Clone the repo

```bash

   git clone https://github.com/HoriaManea/horia-dev-shop.git

```

2. cd horia-dev-shop

3. npm install / npm i

4. npm run dev

## Project structure

- `/src/components` - Reusable React components
- `/src/pages` - Website page components
- `/src/context` - Context API for managing global state
- `/src/data` - Fake JSON data for products
